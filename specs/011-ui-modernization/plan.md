# Implementation Plan: UI Modernization & Redesign

**Branch**: `011-ui-modernization` | **Date**: 2026-04-11 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/011-ui-modernization/spec.md`

## Summary

Modernize the Ghostfolio Family Office UI by:
1. Replacing dropdown-submenu navigation with a top-bar + contextual left sidebar (`mat-sidenav`) pattern
2. Generalizing navigation labels (Dashboard, Valuations, Entities, Documents, Analytics, Admin)
3. Migrating from Angular Material M2 to M3 theming
4. Eliminating Bootstrap dependency in favor of custom token-based utilities
5. Establishing a CSS custom property design-token system
6. Polishing all pages for visual consistency

## Technical Context
